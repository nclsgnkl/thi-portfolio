# Dart Counter

> ℹ️ **Note:** This README was created with the assistance of AI and reviewed by me. The project, its concept and the work presented here are my own.

## About the Project

The Dart Counter is an independent app project designed to make keeping score during darts games as simple and intuitive as possible.

The idea was to create an easy-to-use alternative to manual scorekeeping, with a particular focus on accessibility and a straightforward user experience. The goal was to make the application approachable even for people who are playing darts casually or using a digital scoring tool for the first time.

## Development

The application was developed using an AI-assisted, iterative development approach ("vibe coding"). I used AI coding tools to implement, refine and improve the application step by step, while guiding the process through my own ideas, requirements and feedback.

The project allowed me to explore how AI-assisted software development can support rapid prototyping and bring an independent app idea to life.
