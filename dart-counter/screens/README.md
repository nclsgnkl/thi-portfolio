# Screenshots

> ℹ️ **Note:** This README was created with the assistance of AI and reviewed by me. The project and the work presented here are my own.

This folder contains a small selection of screenshots taken from the Dart Counter app, showcasing its interface and gameplay.

The screenshots cover two available game modes:

- **X01:** The classic darts scoring mode, where players work their way down from a starting score.
- **Cricket:** An alternative game mode with a different scoring approach.

The screenshots provide a visual impression of the app and how the different game modes are presented to the user.
